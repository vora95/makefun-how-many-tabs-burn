Entry for the [How Many Tabs Do You Have Open?](https://make.fun/competitions/u-danu-how-many-tabs-do-you-have-open-d86e783d) bounty on make.fun.

The program writes one number, digits only, to `/output/entry.txt`: **47** — the honest count of open browser tabs. A real, lived-in working session: research, docs, a few half-read articles, and the tabs kept open "just in case".

## Run

```sh
python3 main.py
```

Writes `47` (2 bytes, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
